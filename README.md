# pa-segmentacao-rfm-cluster-ecommerce
Esse repositório é a base de um projeto voltado a segmentação de clientes de ecommerce, baseado em análise RFM e clusterização, com a finalidade de agrupar a base de clientes em perfis, os quais serão utilizados para diferentes estratégias de marketing, visando um aumento de LTV dos clientes atuais e recompra de clientes novos..
